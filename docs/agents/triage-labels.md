# Triage labels

工程 skills 使用五种固定的 triage 角色。本项目使用默认 label 名称：

| Skill 角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求完整，AI agent 可以独立执行 |
| `ready-for-human` | `ready-for-human` | 必须由人执行 |
| `wontfix` | `wontfix` | 明确不处理 |

当 skill 提到某个 triage 角色时，使用表中对应的 GitHub label。
